## 关键联系

- 表示方式决定索引与召回：Dense 对应 ANN，Sparse 对应倒排索引，多向量对应局部交互。
- Query Rewrite、HyDE、Multi-Query 只改变检索入口，不能替代文档质量、重排与生成约束。
- RAGAS 将最终质量拆分为检索证据、上下文排序、回答忠实度和答案相关性。
- Extended Thinking 位于模型内部；ReAct 位于 Agent 外部编排层，两者可叠加。
- Claude Code 将稳定内容放在请求前部以提高 Prompt Cache 命中率，并通过流式 stop reason 驱动 Agent Loop 的错误恢复。
- Claude Code 的 Multi-Agent 状态来自运行时 task event，而不是从自然语言回复猜测；上下文隔离也不自动等于 checkout 隔离。
- Claude Code 的 Grep 工具基于 ripgrep；本地精确搜索与跨仓语义 RAG 是不同规模下的互补方案。
- Claude Code Skills 以名称和描述参与发现、以正文按需扩展能力；frontmatter 调用控制与权限/Hook 安全边界不能混成模型软提示。
- Claude Code 当前公开的跨会话记忆以多作用域规则和 Markdown 索引/主题文件为主；记忆必须与代码、Git、任务系统等当前权威源分开。
