# 00 总体知识网络图

```text
用户问题
  ↓
LLM / Transformer 基础
  ├─ Token → Embedding → Transformer → Hidden State / Logits
  └─ 检索表示
      ├─ Dense Vector：语义相似
      ├─ Sparse Vector：词项与倒排索引
      └─ Multi-Vector：局部 Late Interaction

RAG 在线链路
  ↓
查询理解与增强
  ├─ Query Rewrite：把问题说清楚
  ├─ HyDE：生成假设文档作为检索表示
  └─ Multi-Query：多个检索视角
  ↓
多路召回
  ├─ Dense / ANN
  ├─ Sparse / BM25 / Inverted Index
  ├─ Multi-Vector
  └─ Knowledge Graph
  ↓
RRF 融合 → Cross-Encoder Rerank → Context Packing
  ↓
Grounded Generation + Citation
  ↓
RAGAS / IR Metrics / 人工抽检

Agent 编排
  ├─ MRKL / ReAct / ToT / Plan-and-Execute
  ├─ Extended Thinking：增强每轮内部推理
  ├─ Action / Observation：获取真实外部信息
  ├─ Reflection / Memory：复盘与长期经验
  └─ LangGraph：状态、路由、流式输出

Claude Code Harness
  ├─ 稳定前缀：System prompt → Project context → Conversation
  ├─ Causal Attention / KV Cache：追加内容不改变旧 token 状态
  ├─ Streaming：content delta → message delta → message stop
  └─ Recovery：max_tokens → 扩容重试 → 断点续写

工程承载
  ├─ Python / FastAPI / asyncio
  ├─ Go / Gin / goroutine / gRPC / Protobuf
  ├─ SQL / MongoDB / Redis / Vector DB
  ├─ Kafka / RabbitMQ
  └─ Docker / Kubernetes / Observability / Security
```

## 关键联系

- 表示方式决定索引与召回：Dense 对应 ANN，Sparse 对应倒排索引，多向量对应局部交互。
- Query Rewrite、HyDE、Multi-Query 只改变检索入口，不能替代文档质量、重排与生成约束。
- RAGAS 将最终质量拆分为检索证据、上下文排序、回答忠实度和答案相关性。
- Extended Thinking 位于模型内部；ReAct 位于 Agent 外部编排层，两者可叠加。
- Claude Code 将稳定内容放在请求前部以提高 Prompt Cache 命中率，并通过流式 stop reason 驱动 Agent Loop 的错误恢复。
