# 01.09 预训练、SFT、RLHF 与 LoRA

## 1. 总体性概念

预训练学习语言分布，SFT 学习示范行为，偏好优化让输出更符合人类或产品偏好，推理强化学习可以进一步优化可验证任务上的策略。LoRA 不属于这些阶段中的某一阶段，而是一种减少可训练参数的方法，可用于 SFT 等微调过程。


## 2. 原理性解释

- 预训练通常使用 next-token prediction 等自监督目标。
- SFT 使用输入—理想输出样本，学习指令跟随、格式和任务示范。
- RLHF 通常借助人类偏好数据、奖励模型和强化学习优化策略；DPO 直接利用偏好对优化目标，不等同于强化学习算法。
- RLVR 描述的是“使用可自动验证结果的奖励信号”；GRPO 是可用于这类训练的一种策略优化算法，两者不是同义词，也不是所有推理模型都必须采用同一算法。
- LoRA 冻结原权重并训练低秩增量；它与“训练目标是什么”是两个不同维度。

### 训练阶段、优化目标与参数更新方式要分层理解

预训练让模型学习语言统计规律和语料中的知识；SFT 让模型模仿高质量示范；RLHF、DPO 等方法进一步优化偏好；带可验证奖励的强化学习常用于数学、代码等能自动判分的任务。它们回答的是“用什么数据和目标训练”。

LoRA 回答的则是“更新多少参数”。同一个 SFT 任务既可以全参数微调，也可以使用 LoRA；不能把 LoRA 排成 SFT、偏好优化之后必然发生的下一阶段。

```python
# LoRA 思想：原权重 W 冻结，只训练低秩矩阵 A/B（缩放因子为 alpha/r）
W_eff = W + (alpha / r) * (A @ B)
output = x @ W_eff
```

## 3. 机制流程

1. 预训练。
2. SFT。
3. 按目标选择偏好优化或推理强化学习。
4. 在需要训练的阶段选择全参数更新或 LoRA 等参数高效方式。
5. 部署时结合 prompt、RAG 和工具调用。

### 模型训练/适配的流程选择

```
大规模语料 + 自监督目标 → 预训练 base model
  ↓
人工指令数据 → SFT instruct model
  ├─ 偏好数据 → RLHF 或 DPO 等偏好优化
  ├─ 可验证任务 → 可选的推理强化学习
  └─ 领域示范 → 领域 SFT

参数更新方式（与上面的目标正交）：
  ├─ 全参数微调
  └─ LoRA / QLoRA 等参数高效微调
```

工程上不要把所有问题都归结为“微调”。如果知识频繁变化，优先 RAG；如果输出格式不稳定，优先 prompt/schema/SFT；如果领域风格和任务策略长期稳定，才考虑 LoRA 或全参微调。

## 4. 类比理解

预训练像广泛读书，SFT 像跟着范例练习，偏好优化像根据比较反馈调整答法，推理强化像在可判分练习中优化解题策略；LoRA 像只调节少量关键旋钮。

## 5. 应用举例 / 代码或伪代码

```python
# y = x @ (W + (alpha/r) * A @ B)
W.requires_grad_(False)
A = Parameter(randn(in_dim, r))    # 下投影：随机初始化
B = Parameter(zeros(r, out_dim))   # 上投影：零初始化，保证训练起点 ΔW=0，不破坏预训练行为
y = x @ W + (alpha / r) * (x @ A @ B)
```
