# 03.03 可变默认参数、容器修改与复制语义

> 学习层级：基础

## 1. 默认参数在函数定义时求值

普通函数的默认参数只在函数定义时创建一次。若默认值是 list、dict 或 set，多次调用会共享同一对象：

```python
def bad_append(item, values=[]):
    values.append(item)
    return values

bad_append(1)  # [1]
bad_append(2)  # [1, 2]
```

通常使用 `None` 作为哨兵：

```python
def append_item(item, values=None):
    values = [] if values is None else values
    values.append(item)
    return values
```

这不是“Python 偶尔缓存列表”，而是默认值求值时机决定的稳定语义。

## 2. dataclass 使用 `default_factory`

dataclass 字段需要为每个实例创建新的可变对象：

```python
from dataclasses import dataclass, field

@dataclass
class Document:
    title: str
    tags: list[str] = field(default_factory=list)
```

嵌套对象也可以通过工厂创建：

```python
@dataclass
class Job:
    metadata: dict[str, str] = field(default_factory=lambda: {"status": "new"})
```

也就是说，`default_factory=lambda: ...` 传入的是工厂函数，不是提前创建好的对象。

现代 Python 的 dataclass 会拒绝许多不安全的可变或不可哈希默认值，但普通函数默认参数仍会静默共享。Pydantic 对某些不可哈希默认值会进行复制，不过显式 `default_factory` 的意图更清楚。

## 3. `append`、`extend` 与原地修改

- `append(x)`：把 `x` 作为一个元素放入列表；
- `extend(iterable)`：逐项加入可迭代对象中的元素；
- 两者都原地修改列表，并返回 `None`。

```python
values = [1]
values.append([2, 3])
# [1, [2, 3]]

values = [1]
values.extend([2, 3])
# [1, 2, 3]
```

不要写成：

```python
values = values.append(2)  # values 变成 None
```

## 4. 浅拷贝只复制外层容器

```python
state = {"status": "new", "results": []}
copied = dict(state)

copied["status"] = "done"       # 不影响原字典的外层字段
copied["results"].append("ok")  # 内层 list 仍被共享
```

真正隔离嵌套状态，需要按字段复制、使用不可变更新，或谨慎使用深拷贝。Queue、Task、锁、数据库连接和 Session 等运行时对象通常不适合深拷贝。

## 5. `@property` 改变访问方式，不自动缓存

```python
class Report:
    @property
    def summary(self) -> str:
        return build_summary()
```

每次访问 `report.summary` 都会再次调用 getter。需要缓存时，应显式保存结果，或根据对象模型选择合适的缓存机制。把方法改写为 property 并不会自动得到懒加载缓存。

## 6. 并发环境中的容器修改

在单个事件循环线程中，一段不包含 `await` 的普通 list 操作不会被其他协程从中间切走。但这只说明协作式调度的切换点，不代表：

- 多步骤“先检查、后写入”是事务；
- 多线程访问是安全的；
- 多进程之间会共享同一内存；
- 共享嵌套对象不会产生逻辑竞争。

复杂状态应定义明确的所有者、更新协议和并发边界。

## 7. 排查顺序

遇到“数据莫名被上一次调用污染”时，依次检查：

1. 函数是否使用了可变默认参数；
2. dataclass/Pydantic 字段是否为每个实例创建新对象；
3. 是否只复制了外层容器；
4. 是否把 `append` / `extend` 的返回值重新赋给变量；
5. 是否有多个 Task、线程或请求共享同一状态。
