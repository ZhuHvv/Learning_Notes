# Redis Notes

命令行客户端
`redis-cli [options] [commands]`

- 常见options
> -h 127.0.0.1：指定要连接的redis节点的IP地址，默认是127.0.0.1
> -p 6379：指定要连接的redis节点的端口，默认是6379
> -a 123321：指定redis的访问密码

- commands Redis的操作命令
> 例如 ping：与redis服务端做心跳测试，服务端正常会返回pong

## SQL关系型数据库 vs NoSQL非关系型数据库
|     | SQL | NoSQL |
| :----: | :----: | :----: |
| 数据存储结构 | 有固定行、列的表格 | 文档、键值对、图等 |
| 数据关联性 | 表与表可关联 | 关联需要人为维护 |
| 数据查询 | 使用统一SQL语句进行查询 | 无固定查询语法 |
| 事务 | 支持事务，且必须满足ACID(原子性、一致性、隔离性、持久性) | 或不支持事务、或只需要BASE(最终一致性) |
| 数据存储位置 | 磁盘 | 内存 |
| 扩展性 | 垂直 | 水平 |

## Redis特征
1. 键值型，值支持多种不同数据结构
2. 单线程，每个命令具备原子性
3. 低延迟、速度快 (基于内存、IO多路复用、良好的编码)
4. 支持数据持久化
5. 支持主从集群、分片集群

### Redis数据结构
key-value类型，key一般是`String`，value则不固定

|  类型 | 例子  |
| :---: | :---: |
|基本数据类型|

| GEO  |  {A:(123,456)}  |
