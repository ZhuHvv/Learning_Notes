# Redis 学习总纲与进度

更新日期：2026-11-19。

本文件是课程的统一入口，维护完整范围、学习顺序与最新进度。专题笔记保存具体机制、源码证据、关键疑问与考察记录。下面的未学内容是课程计划，不代表已经讲解、源码核验或实验验证。

## 1. 学习约定

- **方式**：先系统讲清一个适当大小的模块，再由学习者提问；一整块内容没有疑问时，适当用 1～2 道解释机制的题巩固。
- **节奏**：理解准确就推进，薄弱处集中补充；避免每个知识点都先要求个人阐述，也避免过多细碎追问。考察先关注机制理解，再按需要进入情景分析。
- **深度**：整体模型 → 操作入口和调用链 → 数据布局与状态变化 → 异常和边界 → 设计权衡。结合源码，不能只背命令和结论。
- **发散**：数据结构展开增删改查和转换；分布式机制展开断连、超时、重启、重试、切换和数据分歧。按前置性、重要性及常见程度取舍，不一次堆满所有细节。
- **版本**：以 Redis 8.10.3 固定 tag 为主线；历史实现单独注明版本。命令、配置和扩展能力在展开时核对目标版本，源码结论附文件与函数入口。
- **证据**：区分源码事实、机制推演和实测结果。已讲解、学习者已正确复述、补充解释尚未复述、实验已验证分别记录。
- **暂停约定**：整体架构专题保持暂停，择时回访；不因整理笔记或开启新对话而自动重讲。

### 01. 整体架构与命令执行

- 单线程说法的适用范围；主线程、I/O 线程、后台线程与子进程分工。
- 监听连接、accept、客户端对象与读写事件注册。
- TCP 字节流、RESP 协议、输入缓冲区、半条或多条命令解析。
- I/O 多路复用、非阻塞读写、epoll 就绪与 ae 事件循环。
- 时间事件、超时计算、serverCron 与长命令对调度的影响。
- 命令查找、校验、执行、响应缓冲及写回；普通、阻塞与特殊执行路径。
- 线程间队列、通知 fd、锁和客户端处理权交接；版本差异。

回访重点：从连接到响应串起调用链，说明队列保护与对象访问保护的边界；补齐部分读写、断连、错误和漏唤醒防护。

### 02. 基础数据类型、编码与数据结构

- 类型、对象、编码、内存布局的关系；robj、kvobj 与当前版本差异。
- **String/SDS**：int、embstr、raw；长度、容量、二进制安全、预分配、修改和编码转换。
- **Hash/dict**：数据库字典与对象内部字典、哈希冲突、查找与更新、扩缩容、渐进式 rehash；紧凑编码转换。
- **listpack/ziplist**：元素编码、正反向遍历、backlen、历史 prevlen 连锁更新；连续内存搬移。
- **List/quicklist**：分块、定位、两端和中间操作、拆分合并、压缩、节点大小及单独大元素。
- **Set/intset**：统一整数宽度、二分、插入删除、宽度升级、反向搬移、编码转换、交并差与随机取样。
- **ZSet**：紧凑表示、字典与跳表、member 哈希、层高、反向指针、跨度、排名、改分和范围查询。
- 工程边界：同分排序、分数精度、分页、转换停顿、内存与查询成本；大集合和全量命令。

主线已有记录。扩缩容触发细则、Hash 字段过期与特化编码、集合运算分支等仍按第二篇回访清单推进，避免将整个模块一概标为完成。

### 03. 扩展类型与消息场景

- **Bitmap**：与 String 的关系，位偏移和位序；SETBIT、GETBIT、BITCOUNT、BITPOS、BITOP；稀疏高偏移的空间代价；签到、状态标记、统计的键设计。
- **HyperLogLog（基数估算）**：去重计数模型、哈希与寄存器、稀疏和稠密表示、误差、合并；与精确集合的取舍。
- **GEO（地理位置）**：坐标编码与 ZSet 的关系，邻域搜索、候选筛选与距离计算；精度、边界、排序和更新。
- **Stream（流）**：消息 ID、内部索引与紧凑存储；追加、读取、阻塞和裁剪。
- Stream 消费者组：消息分配、待确认记录、ACK、认领、消费者故障、重放、幂等和积压处理。
- List 阻塞命令、Pub/Sub（发布订阅）和 Stream 的语义对比；结合复制和持久化分析消息可靠性。
- Bloom filter（布隆过滤器）在缓存穿透模块展开；其实现与部署方式届时核对，不能混同于 Bitmap 或 HyperLogLog。

扩展重点：从业务需求推导数据模型、操作成本、误差或投递边界，适当做小规模命令实验。

### 04. 命令组合、原子性与事务

- 单条命令、多条命令和应用业务操作的原子性边界；网络往返与执行耗时。
- Pipeline（流水线）：请求批量发送、响应对应、吞吐与延迟、批量大小及缓冲区成本。
- MULTI/EXEC：命令入队与执行；入队错误、执行错误、连接中断和客户端重试。
- WATCH：乐观并发控制、监视条件、失效、重试和竞争。
- Lua 脚本：执行流程、KEYS/ARGV、原子执行范围、错误与已发生写入、长脚本和终止边界。
- 脚本缓存、EVALSHA、NOSCRIPT；Redis Functions（函数）的管理与使用边界。
- 集群多键操作约束；幂等、结果未知和重复提交；数据库事务与 Redis 命令组合的区别。

考察重点：能解释原子性、隔离、回滚和持久性分别解决什么问题，明确各机制的保证范围。

### 05. 持久化与恢复

- **RDB**：快照触发、SAVE/BGSAVE、序列化、临时文件与替换、加载流程。
- fork、Copy-on-Write（写时复制）、页复制、写入强度与内存峰值；创建子进程的停顿。
- **AOF**：命令传播、缓冲、文件写入、fsync 策略、后台刷盘与延迟。
- AOF 重写：重写目的、子进程状态与并发写入、切换流程；当前多文件 AOF 与清单管理。
- RDB 与 AOF、混合形式、启动恢复选择及恢复耗时，按目标版本核对。
- 故障路径：进程崩溃、系统掉电、磁盘满、写入失败、文件截断或损坏、重写失败。
- 备份、恢复演练、恢复点与恢复时间目标；持久化、复制及缓存可重建性的关系。

考察重点：按故障时刻追踪数据到了内存、内核缓存还是持久介质，区分重写和刷盘。

### 06. 过期时间与过期删除

- EXPIRE/PEXPIRE、绝对到期时间、TTL/PTTL、PERSIST；设置、更新、覆盖键时的过期状态。
- 过期元数据与查找路径；逻辑上到期和物理释放的区别。
- 惰性检查与主动过期循环：采样、时间预算、频率和 CPU 取舍。
- 时钟变化、同时到期、访问热点与大量未访问过期键。
- 过期与 RDB/AOF、主从复制、故障切换之间的联系。
- 删除传播、同步释放与异步释放；Hash 字段过期作为扩展分支。

考察重点：能够解释“时间到了”怎样影响可见性、删除时机、资源占用和复制。

### 07. 内存管理与内存淘汰

- 内存构成：数据、对象和索引、分配器、碎片、客户端及复制缓冲；指标口径。
- maxmemory、何时触发淘汰、内存统计和特殊开销；与操作系统内存不足的区别。
- noeviction、allkeys 与 volatile 类策略的适用集合和失败条件。
- LRU（最近最少使用）、LFU（最不经常使用）、随机及 TTL 策略；Redis 的近似实现。
- 采样、候选池、访问时间或频率元数据、衰减及参数影响。
- DEL/UNLINK、lazyfree（异步释放）、大对象释放、内存碎片与主动整理。
- 与过期删除、持久化写时复制、复制缓冲、热数据命中率的相互影响。

考察重点：区分过期、淘汰和释放；能依据数据访问分布解释策略取舍。

### 08. 主从复制与各类异常

- 建链、握手、认证、能力协商和 PSYNC；复制 ID、偏移量与历史关系。
- 全量复制：快照生成、传输、加载、增量衔接；磁盘与无盘路径。
- 部分复制：复制积压缓冲区、可续传范围、连接断开后的判定。
- 命令传播、复制流、ACK、延迟与监控；不同缓冲区的角色和生命周期。
- 异常矩阵：短暂断连、长时间断连、积压覆盖、主从重启、复制 ID 改变、加载失败、慢副本、认证或网络错误。
- 大数据集、全量同步并发、复制风暴、网络带宽、内存峰值和写入速度。
- 异步复制与读到旧数据、读写分离、写入确认、WAIT/WAITAOF 的保证与局限；具体行为按版本核对。
- 主从切换后旧主回归、拓扑改变、过期键处理和数据分歧。

考察重点：能根据复制历史、偏移和缓冲范围分析重连路径，并沿故障时间线解释可能丢失的写入。

### 09. Sentinel：监控与自动故障切换

- Sentinel 的职责、部署拓扑、主从发现、监控和客户端发现方式。
- 主观下线、客观下线、quorum 参数与选举授权所需多数派的区别。
- 领导者选举、纪元、故障转移状态机与重复执行控制。
- 副本选择、提升、其他副本重配置、配置传播和旧主回归。
- 网络分区、监控误判、Sentinel 数量不足、切换超时及配置不一致。
- 客户端连接刷新、认证、重连、请求重试和业务恢复。
- 与异步复制、写入限制和数据丢失的联系；可用性与一致性的边界。

考察重点：分别说明谁判断故障、谁授权切换、谁执行切换，以及各阶段失败会怎样。

### 10. Cluster：分片、路由与集群故障

- 哈希槽、键到槽映射、节点负责范围；hash tag（哈希标签）与多键设计。
- 客户端槽缓存、MOVED 与 ASK、刷新和重试。
- 节点通信、拓扑传播、故障检测、配置纪元与副本选举。
- 槽迁移、扩缩容、导入/迁出状态、迁移中读写和大键影响；区分传统 SETSLOT/MIGRATE 与 8.4 起的 ASM。
- 多键命令、事务和脚本的槽约束；扫描和批量操作的路由。
- 主节点故障、副本不足、网络分区、覆盖不全、旧节点回归。
- 故障切换期间写入结果、可用性、热点槽、迁移负载与客户端兼容。
- 与 Sentinel、客户端分片方案的职责和适用范围对比。

考察重点：串起正常路由、重定向、迁移和故障切换，区分数据分片与复制容灾。

当前收尾：方案对比约 1 小节；认证、地址宣告/NAT、计划内切换和失败处理等必要工程边界约 1～2 小节，再作必要巩固。复制时效参数、自动副本迁移、ASM 完整异常状态机可后续回访；不把已讲主线标为全分支掌握或实测完成。

### 11. 分布式锁与协调

- 互斥需求、锁粒度、租约、持有者身份和资源访问顺序。
- SET NX 加过期时间、原子获取；比较唯一令牌后释放与续期。
- 错误用法：设置与过期分离、直接删除、非原子比较后删除。
- 超时、线程或进程暂停、长业务、续期失败、客户端崩溃、网络结果未知。
- 重试、退避、饥饿、可重入与公平性是否必要。
- 主从切换与重复持有风险；Redlock 的假设、争议与适用边界。
- fencing token（隔离令牌）及资源端校验；幂等、条件更新、数据库约束和其他协调组件的选择。

考察重点：把“取得锁”与“下游资源拒绝过期持有者”分开分析，明确业务需要的保证。

### 12. 缓存故障与热点治理

- **穿透**：不存在的数据请求、参数检查、空值缓存、布隆过滤器、误判和更新。
- **击穿**：热点键失效、请求合并、互斥重建、逻辑过期、后台刷新。
- **雪崩**：集中到期、缓存服务故障或容量变化；错峰、预热、限流、降级、隔离。
- 热点发现、本地缓存、多级缓存、复制热点数据及一致性成本。
- 重建超时、锁持有者失败、重试放大、回源流量与数据库承载。
- TTL 选择、负缓存、陈旧数据容忍度、缓存收益和容量评估。

考察重点：先区分故障来源，再组合手段；明确数据新鲜度、可用性和回源压力的取舍。

### 13. 缓存与数据库一致性

- 业务要求：最终一致、可接受延迟、读己之写及更强保证的边界。
- Cache Aside（旁路缓存）的读写流程；写穿、写回等模式作为对照。
- 更新缓存与删除缓存、操作顺序；并发读写、旧值回填和写入乱序的时间线。
- 缓存删除失败、进程崩溃、数据库提交与消息发送之间的失败窗口。
- 重试、消息队列、事务性发件箱、CDC（变更数据捕获）；幂等、顺序、重复和积压。
- 延迟双删的假设与局限；版本号、条件更新、TTL 和修复机制。
- 多级缓存、主从读取延迟、跨区域部署和故障切换带来的额外窗口。
- 设计可观测、可修复的一致性方案，避免把 Redis 原子执行当作跨系统事务。

考察重点：按并发时序找出旧值出现和存活的条件，再解释方案能覆盖哪些失败路径。

### 14. 性能、可靠性、安全与综合诊断

- INFO、SLOWLOG、延迟监控、客户端与内存指标；采样窗口、服务端耗时和端到端耗时。
- 大键、热点、慢命令、全量返回、扫描、连接数、输出缓冲和网络拥塞。
- Pipeline、批量大小、连接池、超时、重试与背压；吞吐和尾延迟。
- fork、持久化、复制、过期、淘汰、碎片等机制对延迟和容量的共同影响。
- 压测设计：数据分布、读写比例、命中率、并发度和真实网络；可重复的基准与故障演练。
- ACL（访问控制列表）、认证、TLS（传输加密）、网络暴露、最小权限、危险操作与备份保护。
- 升级、配置变更、兼容性、备份恢复、容量规划和故障恢复目标。
- 综合排障与面试表达：观察现象 → 建立假设 → 定位证据 → 修复与验证 → 解释权衡。

扩展分支：按需求加入 Redis 模块和新版本能力，先确认实际版本与部署形态，不挤占核心课程。
