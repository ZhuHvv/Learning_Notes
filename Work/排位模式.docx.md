# 排位模式.docx

1.  初始化阶段
    
    1.  检测本地是否有游戏数据（数据存在本地m\_m\_restore\_game\_scene中）（用于断线重连），有的话还原，走Reconnect逻辑，将本地消息同步到网关
        
    2.  初始化所有可选择武将(排位直接return true，似乎是没有禁将逻辑)
        
    3.  分配身份
        

2v2排位身份抽象为了反贼和忠臣，通过MsgShowFigureToOthers::TYPE\_ASSIGN广播

4.  洗牌 
    
    1.  如果游戏模式是121，122，143
        

新手场控牌堆，给房主加固定的卡

2.  其他情况直接调用PutPlayCardIntoDiscardZone洗牌
    
3.  初始化首回合行动的角色
    
    1.  游戏模式83
        

第一个非人机的角色

2.  游戏模式121，122，143
    

通过fixed\_chapter\_rule\_item得到首位ID，这个东西是根据配置来的，然后找到首个非机器人的ID作为第一轮行动者

3.  游戏模式132
    

根据天梯先手分来确定先后手阵营，然后找到这个阵营中的第一个人作为先手者

（天梯先手分数据来源：mod\_new\_ttrank\_config配置文件，改配置记录了天梯信息，通过LoadDB在DBS中进行存储）

4.  其他模式
    

先读配置，配置没有就随机

6.  分发武将（读配置），设置AI等级
    
7.  读配置
    

通过读配置将m\_ai\_sel\_chr，和m\_use\_sp初始化

2.  武将处理阶段
    

回归模式和新手模式会有专用武将，其他根据配置文件来，并且配置文件中有互斥将框，ruleLogicConfig给将框。通过MsgDealCharacters::TYPE\_SEL;协议选将

step\_wait\_sel\_chr阶段，会根据是否是旁观者区别对待。并且在下一阶段处理国家和势力等消息。选择武将之后会根据特殊模式去添加技能。

3.  处理手牌
    
    1.  通过CGame::onStepAskSelHandCard()初始化手牌构筑
        
    2.  分发手牌

6.  牌局结算
    
    1.  结算流程
        

设置结束标志 -> 清理托管计时 -> 清理物品信息 -> 清理时间条移除游戏ID与Game之间的映射 -> 统计战斗结果 -> 广播统计数据 -> 展示玩家手牌 -> 处理投降玩家 -> 记录数据(经验，战功，使用过的皮肤等) -> 执行游戏核心GameOver(清理牌堆、弃牌区、动作区等)->停止游戏计时

2.  数据流向
    

点赞数据：

初始化检查：首先检查游戏桌指针 m\_pGameTbl是否有效，无效则直接返回，避免空指针操作

数据缓冲区的键值生成：生成唯一标识键 strkey，格式为 "praise\_tbl\_表ID"

临时数据的查找或创建：通过 CTempMsgBufferMg::single()->find(strkey)在缓冲区中查找已存在的数据项

创建新数据：若未找到，则初始化一个 TPraiseTblInfo结构体（数据清零），并添加到缓冲区，设置5000毫秒的存活时间。

重试获取指针：再次查找以确保获得有效指针 ptblinfo

数据重置与更新：使用 memset清空 ptblinfo原有数据，防止旧数据干扰

写入当前游戏桌ID：ptblinfo->tblid = m\_pGameTbl->get\_table\_id()。

玩家信息填充：循环遍历所有座位（0 至 MAX\_TABLE\_SEAT），对于每个有效玩家（CPlayer对象存在），记录其用户ID（userid）和数据库服务器ID（userdbserverid）。

当接收到CLIENT\_DBS\_PRAISE\_REQ协议时可以调取这一数据

战功数据：

遍历桌子上的玩家后通过GetAchievement().SaveToDB();之后储存到DB

7.  与DBS的交互（以游戏结束后计算exp为例）
    

结束后结果通过CGsDbsUpdateUserGameExpScoreReq协议通过CGame::CalcuateResult发送CS转发给DBs关键函数CSNetMg::hand\_msg\_gameserver

到DBS之后，CUserSaveDataMg为一个缓存，将要写入的数据放入这个队列后按照优先级进行储存

发财树模块,客户端直接通过gateway将协议发给dbs后由dbs根据读配置进行计算。

发财树写入读取数据的核心为

friend bostream& operator<<(bostream& bos, ChopTreeData& d);

friend bistream& operator>>(bistream& bis, ChopTreeData& d);
