# 00 总体知识网络图

```text
用户请求
  ↓
Prompt / JSON / XML / 工具 Schema
  ↓
LLM / Transformer
  ├─ token / embedding / attention / FFN / decoder-only
  ├─ logits 生成：回答、工具调用、结构化输出
  └─ embedding 生成：RAG 召回、相似度、重排
        ↓
Agent / RAG / Memory
  ├─ MRKL / ReAct / ToT / Plan-and-Execute：决定下一步行动
  ├─ Reflection / Insight：执行后复盘与经验沉淀
  ├─ IterResearch：长研究任务的固定大小上下文
  ├─ Generative Agents / MemGPT / Mem0 / A-Mem：长期记忆管理
  └─ RAG：召回、融合、重排、生成
        ↓
应用服务层
  ├─ Python FastAPI：async/await、UploadFile、日志、JSON/XML
  └─ Go Gin：Handler、Middleware、Context、Session、SSE、错误处理
        └─ Go 并发：goroutine 调度、channel 通信、select 多路等待、Mutex/atomic 共享状态保护
        ↓
数据与状态层
  ├─ SQL / SQLite / PostgreSQL / MySQL：事务、索引、结构化查询、乐观锁 version
  ├─ MongoDB：文档模型
  ├─ Redis：缓存、会话、限流、Stream、Cluster、Sentinel、Lua 原子操作
  └─ 向量库：Embedding 检索
        ↓
异步与削峰层
  ├─ Kafka：topic、partition、key、replica、leader/follower、ISR、consumer group、offset、retry topic、DLQ
  └─ RabbitMQ：vhost、exchange、queue、binding、routing key
        ↓
部署与运行层
  ├─ REST / RPC / gRPC / SSE / WebSocket
  ├─ Docker / Compose / Kubernetes
  ├─ 正向代理 / 反向代理
  └─ Prometheus / Grafana / OpenTelemetry / 日志
```
