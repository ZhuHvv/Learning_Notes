# 00 总体索引

本索引用于从全局视角组织 LLM、Agent、Python、Go、数据库、消息队列和后端部署网络等计算机相关知识。
本版继续保留已删除的游戏服务器、AIGC/MCP/ML、C++/Lua/序列化专项；在 v5 基础上完成两项修订：一是删除所有知识点文件中“旧版补丁式补充”的补丁式痕迹，将补充内容自然融合进“原理性解释”和“机制流程”；二是补齐今天 Kafka 讨论的 leader/follower/ISR、故障选举、retry topic、DLQ、key、热分区、多消费者语义和幂等处理。

## v6 新增与修订内容

- 新增 Kafka 重试机制、Retry Topic 与死信队列专项文件。
- 新增 Kafka Key、分区策略与热分区专项文件。

## 总体知识结构

```text
LLM / Transformer
  └─ 提供模型理解、生成、Embedding 与工具调用能力
Agent / RAG / Memory
  └─ 在模型能力之上组织任务执行、检索、记忆、反思和长任务研究
Python / FastAPI / Async
  └─ 用于快速实现 AI 应用服务、实验脚本、文件处理与流式接口
Go / Gin / 服务端工程
  └─ 用于高性能后端服务、并发调度、channel 通信、Context 生命周期、SSE 和工程化接口
Database / Redis
  └─ 存储长期数据、缓存、临时状态、索引、限流和分布式状态
Message Queue
  └─ 实现异步解耦、流量削峰、Kafka 事件日志、RabbitMQ 业务路由、重试与最终一致性
Backend / Deploy / Network
  └─ 承载服务运行、代理、容器、监控、流式协议和安全边界
```
