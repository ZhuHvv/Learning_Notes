# 00 后端服务运行时关系图

```text
Client / Browser / App
  ↓ HTTP / SSE / WebSocket / RPC
Gateway / Reverse Proxy
  ↓
Application Service
  ├─ Python FastAPI：适合 AI/RAG 原型、文件上传、异步流式响应
  ├─ Go Gin：适合高性能 API、稳定服务、SSE、认证、中间件
  │     ├─ goroutine：并发处理请求、后台任务、并行 I/O
  │     ├─ channel/select：结果汇总、退出通知、多路等待
  │     ├─ context：超时、取消、请求生命周期传播
  │     └─ Mutex/atomic：保护进程内共享状态
  └─ Agent Orchestrator：计划、检索、工具调用、反思、记忆
        ↓
Data Access Layer
  ├─ SQL：强事务、结构化查询、乐观锁 version、幂等事件表
  ├─ Redis：缓存、会话、限流、临时状态、Lua 原子操作
  ├─ Vector DB：Embedding 检索
  └─ MongoDB：文档型数据
        ↓
Async Layer
  ├─ Kafka：事件流、日志型消息、分区顺序、消费组、offset、ISR、retry topic、DLQ
  └─ RabbitMQ：业务路由、exchange/binding、队列任务、ack/nack
        ↓
Observability / Deploy
  ├─ Docker / Compose / Kubernetes
  ├─ Prometheus / Grafana / OpenTelemetry
  └─ 日志、trace、health check、pprof goroutine 排查、consumer lag 监控
```
